Dividieren: Zahl durch Zahl, gleiche Variablen: Hochzahlen subtrahieren. Kommt eine Variable oben und unten gleich oft vor, fällt sie weg (a : a = 1).

12x : 4 = 3x  ·  12ab : 4a = 3b  ·  18xy : 6xy = 3

15x³ : 5x = 3x²  ·  24a³b² : 6ab = 4a²b

Vorzeichen: gleiche Zeichen → +, verschiedene Zeichen → −. (−18x²) : 3x = −6x · (−20ab) : (−4a) = 5b

Eingabe: Zahl mit Vorzeichen, z. B. −12.
