Zusammenfassung – schreib sie in dein Heft!

✏️ Schreib diese Zusammenfassung mit den Beispielen ordentlich in dein Heft ab.

Zahlengerade: Negative Zahlen liegen links von 0, positive rechts. Je weiter rechts, desto größer.

Vergleichen: −5 < −2  (−5 liegt weiter links)  ·  −0,8 < −0,3  ·  −3/4 < −1/2, weil −0,75 < −0,5

Ordnen: −4 < −1,5 < 0 < 1/2 < 3

Gegenzahl: gleicher Abstand von 0, anderes Vorzeichen: Gegenzahl von −7 ist 7, von 2,5 ist −2,5.

Betrag: Abstand von 0 – nie negativ: |−7| = 7  ·  |2,5| = 2,5  ·  |0| = 0

Zahlenmengen: ℕ = {0, 1, 2, …} natürliche Zahlen  ·  ℤ = {…, −2, −1, 0, 1, 2, …} ganze Zahlen  ·  ℚ = rationale Zahlen (alle Brüche und Dezimalzahlen).
Es gilt ℕ ⊂ ℤ ⊂ ℚ: 5 ∈ ℕ, ℤ, ℚ  ·  −3 ∈ ℤ, ℚ  ·  −0,5 ∈ ℚ

Eingabe: Dezimalzahl mit Komma (−2,5) oder Bruch mit / (−3/4), gemischte Zahl mit Leerzeichen (−1 3/4).
